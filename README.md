# Yuntong Ke — Visual Design Portfolio

English-language portfolio for study, commissions and creative collaboration.

The repository root contains the production build served by GitHub Pages. The maintainable Vite/React project lives in `source/`.

## Local development

```bash
cd source
npm install
npm run dev
```

## Production build

```bash
cd source
npm run build
```

Copy the contents of `source/dist/` to the repository root before publishing through GitHub Pages.
